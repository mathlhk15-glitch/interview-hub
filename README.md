# 2027 대입 면접 셀프 트레이너 — v6.2 (탐구 소유권·심층 꼬리질문 강화)

`interview-hub` v5.1을 기반으로 학생이 **학생부를 분석한 뒤 실제처럼 단계적으로 말해보는 훈련**에 초점을 맞춰 확장한 정적 웹앱입니다.

## v6 핵심 방향

기존 AI-first 원칙은 그대로 유지합니다.

- AI API 없음
- 백엔드 없음
- API Key 없음
- GitHub Pages 정적 배포 가능
- 생활기록부 PDF는 브라우저에서 텍스트만 추출
- 학생이 개인정보를 직접 확인한 뒤 원하는 AI에 프롬프트를 복사
- AI는 모범답안을 쓰는 대신 질문·검증포인트·꼬리질문을 제안
- 녹음은 브라우저 메모리에만 두며 자동 업로드/자동 저장하지 않음

v6에서 가장 크게 바뀐 점은 **분석 결과를 실제 말하기 훈련까지 이어주는 연결**입니다.

## 새 기능

### 1. 학생부 질문 7단계 깊이 지도

AI가 활동을 다음 관점에서 분석하도록 프롬프트와 JSON 스키마를 확장했습니다.

1. 사실 — 무엇을 했는가
2. 동기 — 왜 시작했는가
3. 과정 — 어떻게 했는가
4. 역할 — 본인이 직접 한 것은 무엇인가
5. 개념 — 핵심 개념·원리를 설명할 수 있는가
6. 한계 — 반론·아쉬움·한계는 무엇인가
7. 확장 — 다시 한다면/대학에서 이어간다면 무엇을 할 것인가

모든 활동에 7문항을 강제로 만들지 않고, A/B/C 중요도에 따라 깊이를 다르게 요청합니다.

### 2. 질문별 추천 답변 프레임

- `WHAT → WHY → HOW → SO WHAT + CHECK` : 학생부 탐구·세특·동아리
- `STAR` : 갈등·협업·리더십·실패 경험
- `OREO` : 의견·가치판단
- `정의 → 원리 → 적용 → 한계` : 개념 검증
- `쟁점 → 가치 → 판단 → 근거 → 반론 → 보완` : MMI

AI 결과에 `depth`, `recommendedFrame`, `verificationFocus`를 받을 수 있도록 스키마를 확장했습니다.

### 3. 같은 활동 연속 면접 훈련

AI 활동 인벤토리의 각 카드에 **[이 활동 연속훈련]** 버튼을 추가했습니다.

한 활동에 연결된 여러 질문과 꼬리질문을 저장한 뒤 같은 활동을 계속 파고드는 방식으로 연습할 수 있습니다.

### 4. 말하기 훈련 v6.2

- 30초 / 45초 핵심 / 60초 / 90초 + 실제 답변이 끝났을 때 누르는 `답변 종료`
- `3초 결론 스퍼트`: 3초 안에 결론을 정리하고 첫 문장만 짧게 말하는 순발력 훈련
- 개념 질문에서는 `20초 쉬운 말 설명` 미니 훈련 제공
- 질문별 추천 답변 프레임 자동 선택
- 핵심활동 연속 질문 이전/다음 이동
- `CHECK` 검증 포인트 표시
- 음성 녹음 후 즉시 재생
- 세션 내 질문별 연습 횟수와 최근 실제 답변시간 기록
- 연습 화면에서 바로 `🆘 막혔을 때` 위기대처 카드 열기

### 5. MMI 전용 훈련 강화

기존 간단 메모 화면을 실제 훈련 흐름으로 확장했습니다.

- 직접 찾은 제시문/교사가 만든 상황 입력
- MMI 6단계 사고 프레임
- 제시문 숙지시간 → 첫 답변시간 연속 타이머
- 선택적 음성 녹음
- 6개 후속질문 패턴
  - 선택의 맹점
  - 조건 극단화
  - 관점 전환
  - 원칙 일관성
  - 강한 반박·감정 조절
  - 수정·보완
- 방 완료 후 리셋 훈련

MMI 패턴은 실제 대학 기출이 아니라 **후속질문 사고 훈련용 일반화 패턴**입니다.

### 6. 준비 현황 대시보드

합격 가능성이나 근거 없는 점수는 표시하지 않습니다.

- AI 전체분석 완료 여부
- A급 질문 말하기 완료 수
- 개념 질문 완료 수
- 약점 소명 완성 수
- 총 말하기 시도 횟수
- MMI 훈련 횟수
- 블라인드/공식자료 확인 상태

현재 상태에 따라 다음 추천 행동도 하나만 제시합니다.

### 7. 개인정보 확인 강화

AI 프롬프트 생성 전 단계에 반드시 확인해야 하는 체크를 추가했습니다.

- 이름
- 학교명
- 학번
- 연락처
- 이메일
- 생년월일
- 보호자 정보 등

자동 탐지는 어디까지나 후보 표시입니다. 학생이 직접 원문을 확인하는 원칙을 유지하며, 원할 때만 `개인정보 후보 자동 가리기` 버튼으로 전화번호·이메일·학교명·학번·표시된 이름·생년월일을 치환할 수 있습니다. 자동 가리기 후에도 남은 후보를 다시 점검합니다.

### 8. 2027 초기 대학 면접 DB

교육청 자료에서 **면접 전형 구조만 요약한 시작용 DB**를 넣었습니다.

현재 검증 반영 항목(10개):

- 경상국립대학교 학생부종합(일반/농어촌)
- 부산대학교 학생부종합 일반전형
- 경북대학교 학생부종합(SW특별/영농창업/장애인등대상자)
- 숭실대학교 SSU미래인재전형(면접형)
- 가천대학교 학생부교과 지역균형
- 건국대학교 KU자기추천
- 아주대학교 ACE/첨단융합인재/특수교육대상자(의학과 제외)
- 인하대학교 인하미래인재(의예과 제외)
- 서울과학기술대학교 학교생활우수자
- 중앙대학교 탐구형인재

교육청 2027 면접자료에서 구조를 확인할 수 있는 전형만 우선 넣었습니다. 블라인드 여부처럼 동일 대학 안에서도 전형별 확인이 필요한 항목은 근거가 분명한 경우에만 `시행`으로 넣고, 그렇지 않으면 `미확인`으로 남겼습니다. 앞으로 창원경일고 실지원 대학을 추가하더라도 같은 원칙으로 검증 후 확장하는 것이 안전합니다.

실제 기출문항 원문은 DB에 넣지 않았습니다. DB에서 불러온 정보는 반드시 해당 대학 입학처의 최신 모집요강으로 재확인해야 합니다.

### 9. 자료 연계 배지

AI가 학생부 원문에서 확인할 수 있는 경우에만 `sourceConnections`를 통해 도서·기사·실험·데이터 등 자료 연계를 표시할 수 있습니다.

### 10. v6.2 탐구 복원 지도와 진정성 검증

활동 카드에 `CONCEPT / WHY / PROCESS·LIMIT / SOURCE·OWNERSHIP` 4칸 복원 지도를 추가했습니다.

- **CONCEPT**: 전문용어를 쉬운 말과 기본 교과 원리로 설명할 수 있는지
- **WHY**: 거창한 문구가 아니라 실제 계기·호기심이 무엇이었는지
- **PROCESS / LIMIT**: 막힌 지점, 오류, 수정, 한계가 무엇이었는지
- **SOURCE / OWNERSHIP**: 자료의 출처·신뢰성·한계와 학생이 직접 수행·판단한 부분을 구분할 수 있는지

AI가 학생부 원문으로 확정할 수 없는 내용은 `학생 확인 필요`로 남기도록 프롬프트를 설계했습니다.

### 11. 3단계 심층 꼬리질문

기존의 단순 3층 꼬리질문을 다음 실전 훈련 순서로 고도화했습니다.

1. 개념·진위 — 핵심 개념을 쉬운 말로 설명하고 실제 수행 범위를 확인
2. 과정·시행착오 — 오류·판단 수정·본인 행동을 확인
3. 조건변형·응용 — 변수나 전제를 바꾸거나 반론을 제시해 한계·대안을 확인

이 3단계는 대학 공식 점수표가 아니라 **사고 과정을 깊게 복원하기 위한 훈련 구조**입니다.

### 12. 확장 포인트(선택)

A급 학생부 활동 질문에는 답변을 충분히 한 뒤 실제로 자신 있게 설명할 수 있는 한계·후속탐구를 한 문장 덧붙이는 `확장 포인트` 안내를 보여줍니다. 일부러 답을 숨기거나 모르는 내용을 미끼로 던지는 전략은 사용하지 않습니다.


### 모바일·브라우저 최종 점검 권장

CSS에는 420px/640px 반응형 규칙, 44px 수준의 기본 입력·버튼 높이, `focus-visible` 표시가 포함되어 있습니다. 다만 실제 배포 전에는 학생이 주로 쓰는 기기에서 다음을 한 번씩 확인하는 것이 좋습니다.

- Android Chrome: PDF 불러오기, 마이크 권한, 녹음 재생, JSON 저장/불러오기
- iPhone Safari: PDF 불러오기, 마이크 권한, 녹음 재생, 화면 회전 시 레이아웃
- 390px 전후 화면폭: 대학 DB 모달, 말하기 버튼, MMI 타이머가 가로로 넘치지 않는지

브라우저의 `beforeunload` 경고는 플랫폼 정책에 따라 표시되지 않을 수 있으므로, 화면의 JSON 백업 안내를 함께 유지합니다.

## v6.1 검수 반영 사항

- 답변을 일찍 마치면 `답변 종료`로 실제 말한 시간을 기록
- 화면 이동·뒤로가기 시 마이크·타이머·오디오 URL 정리
- 준비현황의 A급/개념 추천 버튼이 실제 미연습 질문으로 직접 연결
- JSON 백업에서 기타 면접 메모 포함 여부를 사용자 선택
- JSON 불러오기 전 현재 세션 전체 초기화
- 새로고침·탭 종료 시 데이터 소실 경고 + 학생 홈 백업 안내
- 개인정보 후보 자동 가리기 버튼 및 재점검
- MMI 첫 답변을 완료해야 방 완료 횟수 인정, 다음 방 리셋 시 상황·메모·녹음 초기화
- 경상국립대·숭실대 선발배수와 블라인드 정보를 자료 기준으로 보완하고, 검증 가능한 전형을 중심으로 초기 대학 DB를 10개 항목까지 확장

BYOK/API Key 저장 방식은 넣지 않았습니다. 정적 공개 웹앱에서 학생이 API Key를 브라우저 저장소에 보관하는 것은 키 노출 위험이 있고, 이 프로젝트의 `API 없음·프롬프트 복사` 원칙과 충돌하기 때문입니다. 녹음도 IndexedDB/localStorage에 누적 저장하지 않으므로 저장용량 쿼터 문제를 의도적으로 피합니다.

- 활동 카드에 `CONCEPT / WHY / PROCESS·LIMIT / SOURCE·OWNERSHIP` 탐구 복원 지도 추가

- 사설 강의자료에서 얻은 훈련 아이디어는 일반화하여 반영하되, 대학 공식 평가기준이나 합격 공식처럼 표시하지 않음
