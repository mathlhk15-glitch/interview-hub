# 2027 대입 면접 셀프 트레이너 - v7.3 RAG-lite

학생부 전체 맥락 분석 + 교육청 면접자료 RAG-lite 검색 + 근거 원문 검증 + 실전 말하기 훈련을 결합한 정적 웹앱입니다.

## 원칙
- AI API / 백엔드 / API Key 없음
- GitHub Pages 정적 배포 가능
- 학생부 PDF는 브라우저에서 텍스트만 추출
- RAG 지식 DB는 AI 프롬프트 생성 시점에만 지연 로드
- 녹음은 브라우저 메모리만 사용하며 자동 업로드/저장하지 않음
- 자동 받아쓰기(STT)는 기본 OFF. 브라우저/OS에 따라 외부 음성인식 서비스가 사용될 수 있음
- JSON 백업에서 받아쓰기 답변 텍스트와 학생부 근거문장은 각각 별도 선택해야 포함

## v7.3 핵심 변경
1. 4,894개 RAG 후보에 품질 등급을 부여하고 suspicious/reject는 검색에서 제외
2. rag-data.js를 초기 화면에서 제거하고 AI 분석 시점에만 lazy-load
3. 대학명 주변문맥 가중치를 낮추고 질문 자체·전공개념 매칭을 강화
4. 간호계열을 자동 MMI로 간주하던 규칙 제거
5. evidenceQuote 검증을 전체 record 비교에서 sliding-window 유사도 비교로 개선
6. 직접 입력 근거는 '학생부 원문'이 아니라 '입력 자료'로 구분 표시
7. RAG 검색 결과 Top 5·출처·페이지·매칭어 미리보기 추가
8. STT 기본 OFF, 휴대폰은 녹음 우선/받아쓰기 우선 선택
9. 말속도에 CPM(자/분) 추가, 기존 어절/분도 병기
10. TTS timeout fallback, STT 제한적 자동 재연결 추가
11. 백업 schema 7: 받아쓰기 답변 텍스트는 별도 opt-in
12. 중복 dev/legacy 및 오래된 v6.2 README 제거

자세한 RAG 설계는 `RAG_V7_README.md`, 변경 내역은 `V7_2_CHANGELOG.md`를 참고하세요.


## v7.3 정교화
- RAG 검색 근거(매칭 핵심어·선정 이유)를 화면에서 확인할 수 있습니다.
- 교사는 검색 결과에 👍/👎 피드백을 남길 수 있으며 현재 세션의 다음 검색부터 반영됩니다. 피드백은 서버로 전송되지 않습니다.
- 유사한 질문이 상위 결과를 독점하지 않도록 간단한 다양성 재정렬을 적용합니다.
- iPhone/iPad에서는 STT가 제한될 수 있어 녹음+직접입력을 우선 안내합니다.
