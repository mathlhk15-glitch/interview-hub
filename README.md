# 2027 대입 면접 준비 허브

## v4.4 변경사항 — AI 결과 전문 리포트화 및 근거 강화

- AI 결과의 객체(JSON)가 화면에 그대로 노출되던 문제를 제거했습니다. `area/summary/topic/detail`은 제목·설명·근거 영역으로 나누어 학생이 바로 읽을 수 있게 표시합니다.
- AI 프롬프트의 JSON 형식을 엄격하게 지정해 **핵심 기록·핵심 활동·A/B/C 질문·근거 학생부·평가 포인트·꼬리질문·설명 필요·면접관 확인 포인트**를 구분합니다.
- A/B/C 질문에는 가능한 경우 **근거 학생부 영역과 원문 인용**을 함께 표시합니다. 근거가 없으면 숨기지 않고 `근거 문구 미포함` 경고를 보여줍니다.
- `예상 꼬리질문`은 활동명만 표시하지 않고 실제 의문문을 묶음으로 보여줍니다. 이전 형식처럼 주제명만 들어온 경우에도 사실→과정·판단→근거·한계의 범용 꼬리질문으로 안전하게 변환합니다.
- `설명이 필요한 기록`은 성적·출결·진로변경·선택과목 등 **객관적 설명 필요사항**으로 한정했습니다.
- 고교 수준을 상회해 보이는 탐구, 실제 수행 범위, 본인 역할, 관심사 정합성은 별도의 **면접관이 확인할 가능성이 높은 부분**으로 분리합니다. 이전 AI 결과가 이 항목을 `설명 필요`에 넣어도 규칙으로 자동 재분류합니다.
- AI 질문을 질문은행에 저장하거나 30·60초 연습으로 보낼 때 근거 영역·근거 문구·평가 포인트도 함께 보존합니다.
- AI의 사실성 제안은 여전히 학생이 실제 학생부·경험과 일치한다고 확인할 때만 기록/핵심활동/설명 준비에 저장됩니다.

## v4.3 변경사항 — AI 분석 결과 화면 단순화

- AI 결과를 가져오면 더 이상 각 항목마다 `미검토/채택/삭제` 드롭다운과 확인 체크박스를 먼저 요구하지 않습니다.
- 결과를 **핵심 활동 → 핵심 기록 → A 필수 질문 → B 권장 질문 → 설명 필요 → 꼬리질문** 순으로 바로 읽을 수 있게 정리합니다.
- A/B/꼬리질문에는 바로 **30·60초 연습**과 **질문 저장** 버튼을 제공합니다.
- AI가 제안한 핵심 기록·핵심 활동·설명 필요 항목은 화면에서는 바로 읽을 수 있고, 실제로 저장할 때만 “학생부 원문 또는 실제 경험과 일치하는지” 확인합니다.
- C 질문과 `학생이 직접 확인할 내용`은 기본 화면을 복잡하게 하지 않도록 접어서 표시합니다.
- AI 결과가 JSON 형식이 아닐 경우 임의로 모든 줄을 질문 카드로 바꾸지 않고, 원문을 보여주면서 JSON 형식으로 다시 출력받도록 안내합니다.

## v4.2 변경사항 — AI 기능을 용도별로 분리

- **생활기록부 기반 AI 심화분석**: 생활기록부 PDF/붙여넣기에서 추출된 기록만 선택해 분석합니다.
- **내 활동으로 AI 심화분석**: 생활기록부 없이 학생이 직접 입력한 활동만 선택해 분석합니다.
- **내 답변 AI 피드백**: 말하기 연습 화면에서 바로 들어가 답변의 잘된 점·보완점·꼬리질문만 점검합니다.
- 각 버튼은 해당 상황에서만 노출되므로, 사용자가 무엇을 분석하는지 혼동하지 않도록 했습니다.
- 세 기능 모두 AI API를 사용하지 않고 **프롬프트 생성 → 복사 → 원하는 AI에 붙여넣기 → 결과 다시 가져오기** 방식으로 무료 운영됩니다.


`면접 지도 가이드북(ver.260825Final)`의 교육 원칙과 학생용 활동지 A1~A10 흐름을 바탕으로 만든 **무료 · API 없음 · 서버 없음** 정적 웹앱입니다. GitHub Pages에 그대로 올려 사용할 수 있습니다.

## 1. 이번 버전의 핵심

이전 버전은 기능은 많았지만 학생이 직접 `◎진로 / ■학업 / ▲공동체 / ✕설명 필요`를 하나씩 확인해야 해 사용 부담이 컸습니다. v4는 기본 사용 흐름을 다음처럼 줄였습니다.

**생활기록부 PDF 넣기 → 자동 면접 분석 → 반드시 준비할 질문 → 30·60초 말하기 → 면접 직전 한 장**

학생은 체크박스를 정리하는 데 시간을 쓰지 않고 **자기 경험을 말하는 데 시간을 쓰도록** 설계했습니다.

생활기록부가 없어도 주요 활동 1~5개를 직접 입력하면 같은 방식으로 질문을 만들 수 있습니다.

## 2. 원본 가이드북의 의도와 어떻게 연결했나

쉬워졌지만 원본의 핵심 원칙은 줄이지 않았습니다.

- 면접은 대학별 **유형·평가요소·배점** 확인이 중요함 → 기본 분석은 바로 제공하고, 실제 대학 정보는 선택 입력으로 추가 가능
- 학생부 한 기록에서 **동기·과정·개념·역할·한계·연결**을 묻는 구조 → 자동 질문 엔진의 내부 원리로 사용
- 활동은 **사실 → 과정·판단 → 근거·한계**까지 준비 → 모든 핵심 질문에 꼬리질문 3층 제공
- 핵심 활동은 너무 많이 준비하지 않고 **3개 정도를 깊게** 준비 → 자동으로 TOP 3 후보 제시
- 답변은 통째로 외우지 않고 키워드로 말함 → 30초·60초 훈련 및 STAR/OREO 보조 프레임
- 교사·AI가 학생 답을 대신 써주지 않음 → 완성 모범답안 자동 생성 기능 없음
- D-3 이후 새 내용을 늘리지 않음 → D-Day 로드맵과 면접 직전 모드 유지
- 모의면접·자가평가·면접 후 기록 → 상세 준비 도구에서 계속 제공

즉, **입력은 단순화하고 결과와 훈련은 전문적으로 유지**했습니다.

## 3. 학생 기본 사용법

### 가장 쉬운 방법
1. `학생 면접 준비` 선택
2. `생활기록부 PDF로 바로 시작` 선택
3. PDF 첨부 또는 드래그앤드롭
4. 자동으로 핵심 기록과 예상 질문 생성
5. `A · 반드시 준비` 질문부터 30초·60초로 연습
6. 필요하면 `면접 직전 한 장` 인쇄

### 생활기록부가 없을 때
`생활기록부 없이 시작`에서 기억나는 활동만 간단히 적으면 됩니다. 모든 칸을 채울 필요가 없습니다.

## 4. 자동 분석 결과

기본 결과 화면에는 다음만 먼저 보여줍니다.

- 핵심 기록 TOP 3
- A · 반드시 준비할 질문
- B · 준비 권장 질문
- 설명을 준비할 기록
- 각 질문의 학생부 근거
- 꼬리질문 3층
- 30초·60초 말하기 바로가기

`진로·학업·공동체·설명 필요` 태그, 기록 영역 수정, 대학별 세부 평가요소, 블라인드 점검, AI 심화분석 등은 **선택 기능**으로 뒤에 숨겼습니다.

## 5. 자동 분석 방식

외부 AI API를 사용하지 않습니다. 브라우저 안에서 다음 규칙으로 우선순위를 계산합니다.

- 세특·진로·동아리·자율활동 등 기록 영역
- 탐구·분석·비교·조사·실험·발표·설계·검증·수정 등의 활동 표현
- 한계·오류·수정·개선·실패·성찰 표현
- 진로·전공 연결 표현
- 협력·리더십·갈등·책임 표현
- 출결·성적 변화·진로 변경 등 설명 필요 표현
- 선택 입력한 지원 대학·학과

자동 분석은 **실제 면접 질문을 보장하는 예측 서비스가 아니라 면접 준비 우선순위를 잡아주는 규칙 기반 도구**입니다. 대학 공식 모집요강·입학처 안내가 있으면 그 자료를 우선합니다.

## 6. AI 심화분석 — 무료 방식

AI API와 API Key를 사용하지 않습니다.

`AI 심화분석`을 누르면:

1. 보낼 내용 선택
2. 개인정보 후보 확인·삭제
3. 전송 내용 미리보기
4. AI용 프롬프트 생성
5. 프롬프트 복사
6. 사용자가 ChatGPT·Claude·Gemini 등에 직접 붙여넣기
7. AI 결과를 다시 앱에 붙여넣기

AI는 학생의 **완성 답변을 대신 쓰지 않고 질문·점검사항을 제안**하도록 프롬프트가 설계되어 있습니다.

## 7. 개인정보 보호

- 생활기록부 PDF는 서버에 자동 업로드하지 않습니다.
- PDF 원문은 현재 브라우저 메모리에서만 사용합니다.
- 생활기록부 원문·녹음·AI 원문은 localStorage에 저장하지 않습니다.
- JSON 백업에서 학생부 파생 기록과 근거 문장은 기본 제외입니다.
- AI 심화분석을 사용할 때만 학생이 선택한 내용을 직접 복사하여 외부 AI에 전달합니다.
- Google Analytics 등 추적 도구를 포함하지 않습니다.

## 11. 알려진 한계

### 스캔 PDF OCR
이번 버전은 텍스트형 PDF를 PDF.js로 읽습니다. 스캔 이미지형 PDF는 자동 OCR하지 않습니다. OCR 때문에 모바일 성능과 안정성이 크게 떨어질 수 있어, 대신 텍스트 붙여넣기·직접입력 경로를 제공합니다.

### NEIS 표 구조
PDF의 표 배치에 따라 텍스트 순서가 일부 달라질 수 있습니다. v4는 가능한 한 자동으로 선별하고, 필요할 때만 `상세 분석 수정`에서 교정하게 했습니다.

### 면접유형 자동확정
집단·토론·MMI 등은 대학 안내가 없으면 자동으로 단정하지 않습니다. 실제 전형 운영 방식은 모집요강·입학처 자료를 확인해야 합니다.
