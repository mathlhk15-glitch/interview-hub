# 2027 대입 면접 셀프 트레이너 - v7.4 RAG-lite

학생부 전체 맥락 분석 + 교육청 면접자료 RAG-lite 검색 + 근거 원문 검증 + 실전 말하기 훈련을 결합한 정적 웹앱입니다.

## 원칙
- AI API / 백엔드 / API Key 없음
- GitHub Pages 정적 배포 가능
- 학생부 PDF는 브라우저에서 텍스트만 추출
- RAG 지식 DB는 AI 프롬프트 생성 시점에만 지연 로드
- 녹음은 브라우저 메모리만 사용하며 자동 업로드/저장하지 않음
- 자동 받아쓰기(STT)는 기본 OFF. 브라우저/OS에 따라 외부 음성인식 서비스가 사용될 수 있음
- JSON 백업에서 받아쓰기 답변 텍스트와 학생부 근거문장은 각각 별도 선택해야 포함

## v7.4 핵심 변경
1. 질문지 전체 인쇄를 상단 고정바에서 항상 찾을 수 있도록 전역 버튼 추가
2. 질문 생성 이후 대부분의 화면 제목 아래에 [질문지 전체 인쇄] 빠른 버튼 표시
3. 학생 홈에 전체 인쇄 안내 배너 추가
4. AI 분석 결과, 말하기 훈련, 준비 현황, 면접 직전 화면에 인쇄 바로가기 추가
5. 하단 흐름 내비게이션에도 [질문지] 인쇄 단축 버튼 추가
6. 기존 질문 목록의 A/B/C 전체 인쇄와 TXT 저장 기능은 그대로 유지
7. v7.3의 RAG 품질게이트, lazy-load, 근거 검증, RAG 피드백, STT 개인정보 보호 구조 유지
8. 백업 schema 8 유지

자세한 RAG 설계는 `RAG_V7_README.md`, 이번 변경 내역은 `V7_4_CHANGELOG.md`를 참고하세요.
